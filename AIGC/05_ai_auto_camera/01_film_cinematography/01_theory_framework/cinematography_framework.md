# 电影镜头语言 — 核心理论框架

> 电影镜头调度是一门将"视觉语法"与"叙事情感"融合的艺术学科。
> 本文档梳理其完整知识框架，为游戏镜头设计提供理论基础。

---

## 一、核心知识体系总览

```
电影镜头语言
│
├── 1. 景别（Framing / Shot Size）         — 拍多大？
├── 2. 镜头角度（Camera Angle）            — 从哪里拍？
├── 3. 构图（Composition）                 — 怎么摆？
├── 4. 镜头运动（Camera Movement）         — 怎么动？
├── 5. 镜头衔接（Editing / Cutting）       — 怎么切？
├── 6. 景深与焦距（DOF / Focal Length）    — 镜头参数
└── 7. 场面调度（Mise-en-scène）           — 导演控场
```

## 二、景别（Shot Size）

景别决定观众与角色的心理距离。

| 景别 | 英文 | 画面内容 | 情感功能 |
|------|------|---------|---------|
| 极远景 | Extreme Long Shot (ELS) | 人物在环境中极小 | 展示宏观环境、孤独感 |
| 远景 | Long Shot (LS) | 人物全身，环境为主 | 交代位置关系、史诗感 |
| 全景 | Full Shot (FS) | 人物全身为主 | 展示角色动作、姿态 |
| 中景 | Medium Shot (MS) | 腰部以上 | 日常对话、人物关系 |
| 中近景 | Medium Close-up (MCU) | 胸部以上 | 情感表达，最常用 |
| 近景/特写 | Close-up (CU) | 面部 | 强调情绪、细节 |
| 大特写 | Extreme Close-up (ECU) | 眼睛/手等局部 | 极致情绪、震撼强调 |

**规律：景别越近，情感越强烈，观众介入感越深。**

## 三、镜头角度（Camera Angle）

| 角度 | 英文 | 含义 |
|------|------|------|
| 平视 | Eye Level | 中性、客观、平等 |
| 仰角 | Low Angle | 主体强大、威严、英雄感 |
| 俯角 | High Angle | 主体弱小、脆弱、被压迫 |
| 极俯（上帝视角） | Bird's Eye / Top Down | 命运感、宏观叙事、游戏感 |
| 倾斜（荷兰角） | Dutch Angle | 不稳定、心理扭曲、悬疑 |
| 主观视角 | POV Shot | 代入感，让观众成为角色 |

## 四、构图法则（Composition）

### 三分法（Rule of Thirds）
将画面横竖各三等分，主体置于交叉点，视觉平衡而有张力。

### 引导线（Leading Lines）
建筑、道路、河流等线条引导视线指向主体。

### 框中框（Frame within Frame）
门框、窗户、树枝围绕主体，增加画面层次与代入感。

### 180°法则（180-Degree Rule）
对话场景中，摄影机始终保持在两角色连线的同侧，保证空间连续性。违反会造成"越轴"——观众感到迷失。

### 30°法则
剪辑时同一主体的两个镜头，摄影机角度变化需超过30°，否则产生跳切感。

## 五、镜头运动（Camera Movement）

| 运动类型 | 英文 | 描述 | 情感功能 |
|---------|------|------|---------|
| 推镜 | Push In / Dolly In | 摄影机向主体靠近 | 聚焦关注、情绪升温 |
| 拉镜 | Pull Out / Dolly Out | 摄影机远离主体 | 疏离感、揭示环境 |
| 横移 | Tracking / Dolly | 摄影机平行移动 | 跟随行动、展示空间 |
| 摇镜 | Pan | 水平旋转 | 环境扫描、跟随目光 |
| 俯仰 | Tilt | 垂直旋转 | 展示高度、揭示信息 |
| 升降 | Crane / Jib | 上下移动 | 宏大感、戏剧高潮 |
| 手持 | Handheld | 轻微震动 | 纪实感、紧张、混乱 |
| 变焦 | Zoom | 焦距变化（非物理移动）| 突然聚焦，心理冲击 |
| 斯坦尼康 | Steadicam | 平滑跟随 | 流畅跟踪，沉浸感 |
| 希区柯克变焦 | Dolly Zoom | 推摄+拉焦同步 | 极度眩晕、认知冲击 |

## 六、镜头衔接与剪辑（Editing）

### 剪辑节奏理论
Walter Murch（《眨眼之间》）提出剪辑的六个标准（重要性排序）：

1. **情感（Emotion）** — 50%权重：剪辑点是否保留/强化情感？
2. **故事（Story）** — 25%：是否推进了叙事？
3. **节奏（Rhythm）** — 10%：节奏是否合适？
4. **视线（Eye-trace）** — 7%：观众视线是否被顺畅引导？
5. **银幕方向（2D plane）** — 5%：空间关系是否清晰？
6. **三维空间（3D space）** — 3%：三维连续性是否维持？

### 常见剪辑方式

| 剪辑类型 | 功能 |
|---------|------|
| 匹配剪辑（Match Cut） | 形状/动作相似的两个镜头，流畅过渡 |
| 跳切（Jump Cut） | 时间跳跃，节奏感，戈达尔风格 |
| 对切（Cross-Cut） | 交替切换两个场景，制造对比/悬念 |
| 插入镜头（Insert Shot） | 打断叙事插入细节特写 |
| 反应镜头（Reaction Shot） | 展示角色对事件的反应 |
| 过肩镜头（Over-the-Shoulder） | 对话中最常用，保持视线关系 |

## 七、场面调度（Mise-en-Scène）

导演对画框内所有视觉元素的控制：

- **灯光** — 硬光/软光，高调/低调，阴影方向
- **色彩** — 色调情绪，暖色/冷色象征
- **演员走位** — 前景/背景层次，角色位置传递权力关系
- **道具与环境** — 暗示人物性格、故事背景

## 八、情绪-镜头对照速查表

| 情绪/叙事目的 | 推荐镜头组合 |
|-------------|------------|
| 孤独、渺小 | ELS 远景 + 高角度 + 静止固定 |
| 英雄登场 | 仰角 + 慢推 + 宏大配乐 |
| 紧张对抗 | 快速对切 + MCU 特写 + 手持抖动 |
| 情感爆发 | 从 MS 缓缓推至 CU/ECU |
| 揭示秘密 | 插入特写 ECU + 静止 |
| 史诗场面 | 升降镜头 + ELS + 宽银幕构图 |
| 迷失/恐惧 | 荷兰角 + 快速摇镜 + 手持 |
| 亲密/温柔 | 软焦 + MCU + 缓慢横移 |
