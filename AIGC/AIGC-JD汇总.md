## 二、逐岗位要点（保留原文关键项）

### 1. 米哈游 · AI研发工程师（AIGC方向）

**职责**
1. 把最先进的 AIGC 技术落地到游戏研发管线，转化为优化生产、升级玩家体验的解决方案。
2. 针对图像、视频、Mesh 等多媒体数据，构建"数据处理 → 算法设计 → 模型训练 → 推理优化"多链路，优化 AIGC 在项目生产中的表现。
3. 负责自动/半自动 3D 资产生成工作流的探索、构建、优化，提高 AI3D 生成资产的可用性。
4. 与美术、程序、策划团队合作，建立 AI 驱动的先进生产模式。
5. 跟踪 AIGC 最新动态，快速评估并落地前沿算法。

**要求**
1. 熟悉 AIGC 原理与最新进展（图像/视频/3D 内容生成、多模态、3D 动作）。
2. 扎实编程能力，具备生成式模型训练、数据处理、可控推理能力。
3. 系统思维与工作流构建能力，链路设计闭环；以落地结果为导向，关注效率与实际可用性。
4. 有 AI+游戏研发提效经验为佳。
5. 主动性好、沟通能力强、热爱游戏。

3. **性能/功耗/稳定性工具链**：基于 Nsight、RenderDoc、PIX、Radeon GPU Profiler、Intel GPA / PresentMon、Arm Performance Studio、Snapdragon Profiler、Xcode GPU Capture 建立跨平台性能分析、GPU 问题定位、功耗温控分析与回归验证流程。
4. **中台沉淀与跨团队支持**：把排查经验、厂商接入、平台差异分析沉淀为文档、规范、调试流程，支撑项目组、美术 TA、技术 TA、图形渲染与框架团队。

**要求**
1. C/C++ 扎实，具备底层工程开发能力；了解 C#、Python 或其他脚本工具链者优先。
2. 熟悉 GPU 渲染管线、Shader 开发与常见图形性能瓶颈，理解带宽、Overdraw、同步、资源绑定、PSO/Shader 编译、显存管理。

4. 熟练使用至少一款主流图形调试或性能分析工具（同上清单）。
5. 具备复杂图形问题定位能力：GPU Crash、驱动异常、渲染效果错误、Shader 编译故障、平台差异、性能回退。
6. 熟悉 PC GPU、移动端 GPU、主机平台至少一类硬件架构与驱动特性（NVIDIA GeForce、AMD Radeon、Intel Arc、Apple GPU、Adreno、Mali/Immortalis）。
7. 有 UE / Unity 渲染模块开发，或游戏/引擎厂商跨平台图形适配、性能调优、GPU 故障排查实战经验者优先。
8. 优秀的问题拆解、文档沉淀与跨团队协作能力，能把个人经验转化为可复用的中台标准方案。

**加分**
- DLSS / FSR / XeSS / MetalFX / Snapdragon GSR / Arm ASR / PSSR 等超分、插帧、低延迟方案落地接入。
- 光追、GPU Driven、大规模可见性剔除、Instance/Indirect Draw、Cluster/Tile Based Rendering、VRS、Compute-Based Rendering 研发或落地。
- 熟悉 Bindless、Mesh Shader、Work Graphs、Ray Tracing、Ray Reconstruction、Denoising、DirectStorage。

- 主机平台性能优化、硬件预算管控、PSSR / 光追适配、平台认证。

- 能持续跟进硬件厂商与平台技术更新，独立输出技术研判、验证方案与内部技术分享。

## 四、几点规律性结论

1. **"Unity + 深度学习"是当前最稀缺的组合**：乐元素、鹰角、Garena、米哈游四个岗位同时要 Unity/C# 实时开发能力 + PyTorch 训练部署能力，且都把"模型跑在客户端实时环境（延迟/内存/推理优化）"写进核心职责。这和传统客户端/引擎岗的差别就在这一层。
2. **"AI 提效"已从加分项变成独立岗位**：米哈游（AIGC 管线）、bilibili（研发效能负责人）、网龙（Vibe Coding 复刻）、微软（Agent 平台）四个岗位的 KPI 都是"把 AI 变成可复用、可推广的生产方式"，而不是做一个 demo。
3. **Agent 工程与游戏引擎正在合流**：Garena 直接要求"引擎中 Agent 工作流的搭建与调优"，字节要求"Agent + 特效/游戏/3D 组合经验优先"，bilibili 要求"Code Agent 落地经验"。
4. **库洛是唯一的纯图形底层岗**：与 AI 关系最弱，门槛也最硬（图形 API + 硬件架构 + 驱动级排查），薪资定位 30-60K，适合作为"技术深度"方向的对照项。
5. **经验年限与实际要求常不一致**：Garena 抬头写"经验不限"但正文要求 5 年以上引擎经验；网龙抬头 3-5 年、正文写 5 年以上；微软抬头 10 年以上、正文写 8 年以上——投递前按正文准备。
6. **按年限对号入座**：1-3 年 → 米哈游；3-5 年 → 鹰角、网龙；5-10 年 → 库洛、Garena、微软（8+）、bilibili（负责人）；应届 → 字节校招（仅 2027 届）。
